# 🧮 Quantix — Modern Web Calculator

Calcify is a simple and responsive calculator built using **HTML, CSS, and JavaScript**.  
It provides a clean user interface and supports basic arithmetic operations directly in the browser.

## 🚀 Live Demo

👉 **[Try Quantix](https://viveknahar17.github.io/Calcify/)**

---

## 📌 Features

- ➕ Addition
- ➖ Subtraction
- ✖️ Multiplication
- ➗ Division
- 🔢 Decimal number support
- 🧹 Clear/reset functionality
- ⌫ Delete/backspace functionality
- 📱 Responsive design
- ⚡ Instant calculations using JavaScript
- 🎨 Clean and user-friendly interface

---

## 🛠️ Technologies Used

### HTML5
Used to build the structure of the calculator and its UI elements.

### CSS3
Used for:
- Calculator layout
- Button styling
- Responsive design
- Colors and typography
- Hover and interaction effects

### JavaScript
Used to implement:
- Calculator logic
- Arithmetic operations
- Button interactions
- Input handling
- Display updates
- Clear and delete functionality
